# Артефакты проверки v7

Основной отчёт: `../EVAL_V7_2026-09-07.md`.

- `holdout-before-fixes.yaml` — 12 вопросов по шести компаниям, не входившим в предыдущие сценарии. Ожидания зафиксированы до просмотра ответов кандидата H. После обнаруженных ошибок этот набор использован для исправлений кандидата I и далее считается регрессией.
- `holdout-before-fixes-summary.json` — результат первого запуска этого набора, по три повтора на каждой модели. Он сохранён без улучшения оценок задним числом.
- `oracle-corrections.json` — четыре отдельно описанные ошибки ожиданий более раннего набора. Исторические результаты не переписаны.
- `regression-gold.yaml`, `regression-ids.txt` — точный набор из 88 сценариев финального повторного прогона.
- `full-manifest.json`, `regression-manifest.json`, `environment.json` — коммит, хеши исходников и данных, настройки моделей и окружение.
- `canonical.json` — 2 200 проверок адресов источников, сумм и банковских меток в детерминированных ответах на всех 200 отчётах. Это проверка инвариантов, а не 2 200 независимых ответов модели.
- `judge-audit-examples.json` — два ложных срабатывания судьи на промежуточном кандидате I, сверенные с исходным отчётом. Баллы не исправлялись.
- `judge-repeatability-example.json` — одинаковый видимый ответ получил от судьи 0 и 5 на кандидате N. Различия контекста инструментов и работа самого судьи влияют на оценку.
- `locked-gold.yaml`, `locked-before-run.json` — 12 дополнительных составных вопросов, зафиксированных до вызовов моделей на кандидате P. `locked-before-fixes-summary.json` сохраняет первый результат. После обнаруженных ошибок вопросы использованы для исправлений Q и теперь тоже считаются регрессией.
- `locked-manifest.json`, `locked-summary.json` — повтор этого набора на финальной сборке.
- `code-verification.json`, `server-checks.json` — локальные проверки, HTTP/SSE-сценарии на VPS и восстановление резервной копии.
- `pre-release-q-metrics.json` и соответствующие summary — полный результат предыдущей сборки Q до исправления сравнения судебных ролей. Это отдельный прогон; он не смешан с финальными метриками S.
- `comparison-audit-q.json` — проверка спорных ответов Q по исходным данным; среди них реальная ошибка суммирования судебных статусов, исправленная в R.
- `court-regression-*` — шесть дополнительных повторов судебного сравнения на финальной S, включая исходные ответы и баллы.
- `derived-age-audit-r.json` — пример корректного расчёта возраста по датам, который судья ошибочно назвал выдуманным фактом.
- `status-availability-fix.json` — проверенный ответ S на ранее падавшее уточнение текущего статуса без обращения к модели.
- `quota-interruptions.json` — неполные попытки из-за превышения общей квоты при перекрытии тестовых процессов; в итоговые полные прогоны они не подмешаны.
- `final-factual-audit.json`, `final-enforcement-audit.json` — проверка флагов судьи финальной сборки по исходным значениям, без изменения оценок.
- `RESIDUALS.md` — разбор оставшихся расхождений автоматических оценок и границ проверки.

Сырые ответы, трассы, промежуточные кандидаты, сведения об окружении и резервная копия чатов хранятся локально в `runs/v7-audit/` и `runs/selectel-v7/`. Резервная копия чатов и настройки с ключами не включаются в Git.

Оценка автоматического судьи и совпадение с ожидаемыми подстроками не равны независимой проверке банковским экспертом. Подтверждаемость в старом отчёте — составная метрика существующего тестового раннера, а не доказанная доля фактически верных ответов в реальном потоке.

## Воспроизведение

Используйте коммит из манифеста и зависимости из `uv.lock`. Файл с ключами остаётся вне Git. Новый запуск должен писать в новый каталог; исторические результаты не перезаписываются.

```sh
uv sync --frozen
PYTHONPATH=src uv run pytest -m 'not live'
PYTHONPATH=src uv run python -m evals.canonical --out runs/canonical-check.json
```

Для живого полного прогона — `python -m evals.paired` с `--env-file`, обеими моделями из манифеста, `--suite all --repeats 1 --concurrency 4 --judge --out НОВЫЙ_КАТАЛОГ --execute`. Для повторного набора добавьте `--gold docs/evaluation-v7/regression-gold.yaml --only "$(cat docs/evaluation-v7/regression-ids.txt)" --repeats 3`.

Без `--execute` команда выполняет только подготовку. Для сопоставления результатов сохраняйте полный манифест, исходные ответы, все реплики диалогов и сведения об использовании токенов. Время ответа и время работы судьи измеряются отдельно.
