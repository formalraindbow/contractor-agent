# Задержка перед первым ответом: 7 сентября 2026

На стенде зафиксированы 502/503 от Polza и повторы OpenAI SDK с ожиданием
60 секунд. Сервер не перегружен: получение карточки занимает 11 мс.
На вопрос «стоит ли иметь с ними дело?» из карточки МАКСМАРКЕТ старый агент
потратил 28,55 с, сделал поиск и два последовательных чтения отчёта,
а затем выдал карточку вместо прямой рекомендации.

Изменения:

- Временные ошибки соединения и 5xx повторяются один раз с паузой до 2 с;
  429 и ошибки авторизации не получают этот быстрый повтор. Судья сохраняет
  прежнюю политику повторов SDK.
- `LLM_FAST_KNOWN_COMPANY=true` пропускает планирование чтений для известных
  ИНН в вопросе и однозначных вопросов с местоимениями из карточки/сравнения.
  Данные всё равно читаются через MCP, рекомендацию составляет модель,
  проверка фактов и цитат сохранена. Новые названия проходят обычный поиск.
- Исправлено распознавание «иметь с ними дело» как запроса рекомендации.
- Короткое «Проверь МАКСМАРКЕТ» больше не отсекается как посторонний ввод.

На отдельном контейнере того же VPS первый ответ на исходный вопрос занял
1,53 с и начался с рекомендации, затем привёл подтверждения из отчёта.
Это единичные замеры, а не новая средняя задержка или оценка качества.
Модель остаётся `openai/gpt-oss-20b`, Polza, порядок провайдеров `groq,akashml`.

Проверка: Ruff и 529 тестов без внешней модели прошли. Включены регрессии
по временным ошибкам, ограничению запросов, новой компании, первому вопросу
из карточки и сохранению MCP-оснований. Полный LLM-eval не повторялся;
предыдущие метрики качества нельзя приписывать этому изменению.

Для отката ускоренного пути достаточно `LLM_FAST_KNOWN_COMPANY=false`
и пересоздания только API-контейнера. Чаты хранятся в прежнем SQLite-томе.
