## Повторный запуск проверки

`uv run python scripts/review_acceptance.py` делает реальные запросы к модели.
`node scripts/review_ui_smoke.cjs` проверяет интерфейс с контролируемым ответом при вводе.
`node scripts/record_review_demo.cjs` выполняет три настоящих прохода и перезаписывает запись.
Для браузерных скриптов требуется Playwright с FFmpeg и установленный Chrome;
путь к пакетам можно передать через `NODE_PATH`, для записи путь к Chrome — `CHROME_PATH`.
