## 2. Второй судья другого семейства — один перепрогон

**Что:** пересудить кэш ответов целевой модели (v2) судьёй `deepseek-v4-flash` вместо
`gpt-oss-120b`; вывести вторую строку оценок и долю совпадений двух судей по вопросам.
**Зачем:** сейчас gpt-oss-120b судит gpt-oss-20b — одно семейство. На воркшопах 4.09
и Низамов (со ссылкой на arXiv 2404.13076), и Потехин назвали это ошибкой калибровки:
судья и целевая должны быть из разных семейств, иначе оценка смещена. Если мы
показываем «0 % выдуманных фактов», это первый вопрос эксперта.
**Цена:** `JUDGE_MODEL` уже вынесен в `.env`, deepseek подключён как контрольная модель,
ответы в кэше — перепрогон только судьи. По времени похоже на один прогон судьи.
**Выход:** таблица «судья A / судья B / совпали в N из 50» — одна строка на слайд.
