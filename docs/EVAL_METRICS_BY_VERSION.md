# Метрики тестирования по версиям

Обновлено 07.09.2026 после контрольного прогона и обновления стенда. Основные метрики для новых запусков: **trajectory match 0–100**, целевой score **85**, **доля сценариев с галлюцинациями**. Оценки относятся к связке «промпт + код + модель + провайдер + эталон + судья».

## Как читать результаты

| Метрика | Что означает |
|---|---|
| Score 0–100 / trajectory match | Средняя оценка соответствия ответа и вызовов инструментов эталону. Hard проверяет также порядок вызовов. Это не процент истинных утверждений. |
| Score ≥85 | Сколько сценариев достигли целевого балла из всех завершённых. Неполученная оценка не считается успехом. |
| Галлюцинации, % | 100 × число сценариев с hallucination score <1 / число сценариев, оценённых этой метрикой. В одном диалоге достаточно одного флага. Это не доля ошибочных слов или утверждений. |
| Покрытие | Сколько оценок реально получено. Пример: 0/23 = 0% при 24 сценариях означает один неоценённый сценарий, а не 24 успешных. |
| Ошибки судьи | Не удалось получить одну или обе оценки. Их нельзя заменять нулями качества или засчитывать как успех. |
| Медиана ответа | Время одной реплики агента без судьи. В старых замерах время считалось иначе. |

## v3–v7: исторические оценки старого судьи

Судья Qwen3-235B оценивал ответы по другой рубрике на шкале 0–5. Ниже эта шкала переведена в 0–100 формулой **балл ×20**. Например, 4,18/5 = 83,6/100. Это **оценка старого судьи**, trajectory match в этих прогонах не измерялся. Новые оценки GLM нельзя напрямую сравнивать с этой таблицей.
