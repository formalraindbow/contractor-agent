Как мы проверяем агента
Мы не верим агенту на слово. К двенадцати компаниям составлены пятьдесят вопросов с заранее известными правильными ответами: где ответ в отчёте есть, где его нет и агент обязан отказаться, где нужен вывод из нескольких фактов и где нужна проверка компании целиком. Каждый ответ сверяет код, затем его оценивает вторая нейросеть, более сильная, чем та, что внутри агента.
