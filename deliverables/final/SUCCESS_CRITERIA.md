# Критерии успеха и результаты проверки

Кейс формулирует критерий так: агент отвечает на большинство вопросов по отчёту
и не выдумывает. Кейсодатель на QA добавил, что отказ при отсутствии данных это
правильный ответ, а метки банка пересчитывать нельзя. Из этого мы вывели четыре доли
и судью: вторую модель, которая оценивает каждый ответ по рубрике из списка ниже. Ошибки разной цены считаем отдельно: пропущенный красный фактор стоит денег,
ложная тревога стоит времени.

## 1. Критерии

| Критерий                       | Как считается                                                 | Порог |
| ------------------------------ | ------------------------------------------------------------- | ----- |
| Подтверждаемых ответов         | проверки кодом пройдены и судья поставил не меньше 4 из 5     | ≥ 0,8 |
| Корректных отказов             | вопросы, где данных в отчёте нет: агент отказал и не домыслил | ≥ 0,9 |
| Выдуманных фактов              | судья нашёл в ответе факт, которого нет в данных инструментов | 0     |
| Пропущенных критичных факторов | в карточке есть красный фактор, агент его не назвал           | 0     |
| Судья по рубрике               | средний балл от 0 до 5                                        |       |
| Неверных ссылок                | число верное, адрес поля не тот                               |       |

Судья обнуляет ответ, если пропущен красный фактор, назван факт, которого нет
в данных или дан ответ по существу там, где данных нет. Снижает балл: отказ при наличии данных −2,
число по судам без роли и периода −2, метка пересчитана или объяснён её расчёт −2,
нет даты отчёта −1, вердикт без условий −1, ложная тревога на чистой карточке −1,
ярлык на контрагента −1. Тон и длину судья не оценивает.

## 2. Как проверяли

Эталон: 50 вопросов на 12 карточках. Карточки выбраны под сломанные места в данных:
банкротство при зелёных метках, исключение из ЕГРЮЛ при нуле негативов, блокировка
счетов при низком риске, метки, противоречащие друг другу, чистая компания, компания
с 1744 производствами и тремя разными числами судов, редкие секции.

| Тип вопроса                  | Сколько | Что проверяет                                                   |
| ---------------------------- | ------: | --------------------------------------------------------------- |
| карточка, «проверь компанию» |      12 | вывод совпал с разметкой, критичные факты названы               |
| ответ есть в данных          |      14 | нашёл поле, назвал число с ролью, периодом и датой              |
| ответа в данных нет          |      12 | отказал, не домыслил, назвал, чего не хватает                   |
| нужен вывод из полей         |      12 | собрал факты из нескольких разделов в действие для пользователя |

Треть вопросов про суды, 12 из 38: это самое запутанное поле отчёта и первое, о чём доуточняют по словам кейсодателя. Ожидаемый вывод по каждой из 12 карточек проставлен
до прогонов: «на условиях» 6, «проверить до договора» 4, «можно работать» 2. К каждому
вопросу записаны ожидаемый ответ по данным инструментов, поле-источник, обязательные
и запрещённые формулировки.

Сначала код проверяет обязательные подстроки, запрещённые формулировки, валидность
адреса поля и совпадение вывода. Потом судья, модель gpt-oss-120b, получает вопрос,
ответ агента и сырые данные инструментов и ставит балл по рубрике. Ответ считается
подтверждаемым, только если пройдены оба слоя.

Прогнали три раза: целевую модель gpt-oss-20b с первой и текущей версией промпта и контрольную большую
deepseek-v4-flash. Один повтор на вопрос. Ответы и вердикты судьи сохранены, проверки
пересчитываются из кэша при изменении кода. Прогон повторяется из репозитория одной
командой, нужен только ключ модели.

## 3. Результаты

| Модель | Подтверждаемых | Отказов | Выдумок | Неверных ссылок | Пропущено критичных | Судья | Секунд на вопрос |
|---|---:|---:|---:|---:|---:|---:|---:|
| gpt-oss-20b, первая версия промпта | 45 % | 100 % | 6 % | 12 % | 8 % | 3,54 | 34 |
| gpt-oss-20b, текущая версия промпта | 76 % | 100 % | 0 % | 4 % | 0 % | 4,52 | 38 |
| deepseek-v4-flash, контрольная | 76 % | 100 % | 2 % | 2 % | 0 % | 4,44 | 155 |

Целевая модель с текущей версией промпта по типам вопросов:

| Тип | n | Проверки пройдены | Судья |
|---|---:|---:|---:|
| карточка | 12 | 100 % | 5,00 |
| ответ есть | 14 | 71 % | 4,29 |
| ответа нет | 12 | 100 % | 4,83 |
| нужен вывод | 12 | 67 % | 4,00 |

Порог по отказам, выдумкам и пропущенным критичным выполнен. Порог по подтверждаемости
нет: 0,76 при цели 0,8. Малая модель с текущей версией промпта дала те же доли, что контрольная
большая, при ответе в четыре раза быстрее. Разница между первой и текущей версией это правки промпта
по разбору провалов первой версии. Две оговорки к цифрам: судья той же линейки моделей, что
агент, и разметки руками для сверки с судьёй нет.

Девять провалов текущей версии:

| Причина | Вопросов | Примеры |
|---|---:|---|
| Суды без роли: не назван истец или ответчик | 5 | БИЛД-ЮГ и ГДК про суды, РЕМСТРОЙ М и ПСК «ТАЙФУН» про отсрочку, СКВ СПБ про вывод по судам |
| Не названо второе число: завершённые производства, сумма по годам, чистые активы | 3 | МАКСМАРКЕТ про приставов, ЛЕ МОНЛИД про суды, ГДК про метку при блокировке |
| Нет даты отчёта или суммы убытка | 1 | СПОРТ про метку при убытках |

Пять из девяти закрываются одним правилом: обе роли и оба числа называть всегда, даже
при нуле. Правило и проверка кодом добавлены после разбора провалов.

## 4. Что дальше

К пилоту: второй судья другого семейства; разметка руками 12 карточек и выборки
ответов; три повтора на вопрос; две карточки с командой в названии. Порог входа:
ноль пропущенных критичных факторов и ноль выдуманных на свежей выгрузке.
