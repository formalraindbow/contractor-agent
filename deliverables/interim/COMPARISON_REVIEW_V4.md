- **Знак результата ГДК за 2024 год.** Обе версии назвали убыток. develop ответил коротко по существу; новая версия показала более широкую карточку с дополнительными рисками. Здесь её подробность избыточна.

## Поведение и ограничения

- Неоднозначный поиск теперь выводит найденные варианты кодом. Это устраняет зависимость списка компаний от формулировки модели; до выбора ИНН карточка не создаётся.
- Строгий валидатор иногда приводит к более длинному ответу из рассчитанных данных. Вопрос об одном показателе может получить общую карточку. Языковое оформление таких резервных ответов ещё можно улучшить. В свободном ответе по налогам осталось служебное имя flag_taxArrears; сценарный тест проверяет наличие факта, а не всю стилистику.
- Числовая проверка не доказывает полный смысл свободного текста. Отклонённые цитаты черновиков остаются в журнале; они не равны ошибкам в показанном ответе.
- Полный набор из 50 вопросов `gold.yaml` с обновлённой рубрикой в этом запуске не прогонялся. Сессии теперь сохраняются в локальную SQLite. Для нескольких банковских процессов нужны общая БД сессий, gateway с проверкой доступа к разговору и нагрузочные испытания.
- Docker daemon недоступен: сам образ не запускался. Исправлен состав образа; wheel собирается, содержит UI и evals и импортирует API в изоляции.

## Исправление потери разговора

При проверке стенда пользователь обнаружил, что после нескольких перезапусков страница сохраняла сообщения, а InMemorySaver на сервере терял контекст. Исправлено в `2bf10c7`: AsyncSqliteSaver сохраняет историю, выбранные ИНН и цель между запусками; интерфейс восстанавливает разговор через постоянный идентификатор чата после обновления страницы. Техническая ошибка сети заменена понятным сообщением, повтор относится к конкретному вопросу. Текущие доступные разговоры перенесены перед перезапуском. У уже утраченного разговора МАКСМАРКЕТ восстановлен ИНН из первого вопроса пользователя; утраченные сервером ответы не выдаются за восстановленную историю.

Отдельный регрессионный тест закрывает приложение после общей проверки, создаёт новое приложение и задаёт вопрос о свежей выписке без ИНН: проверяются компания, цель, видимая история, цитата и дата. Пройден и живой сценарий на Yandex после смены процесса; обновление страницы сохранило вопрос и ответ. Помощник теперь прямо сообщает, что не получает свежую выписку, и показывает статус из загруженного отчёта. Вопросы о свежих выписках проходят отдельное ограничение возможностей; это не интеграция с ФНС.
